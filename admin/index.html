Super Admin

Full platform access. Can manage all admin users, trust review, caregivers, clients, finance, and settings.

Admin Manager

Operational admin. View & manage caregivers, clients, requests. Can approve trust items and add notes. Cannot manage admin users.

Verification Reviewer

Focused on Trust Passport review. Can view and approve trust modules. Cannot access finance or manage admin users.

Support Agent

Customer support. View basic caregiver/client profiles and request status. Add support notes. Cannot manage verification or payments.

Finance Admin

Invoice and payments. View earnings, invoices, payment status. Cannot manage verification or admin users.

Read-Only Auditor

Read-only. View selected areas and reports. Cannot edit, approve, delete, or export sensitive data.
